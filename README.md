# 验证码自动识别助手 (CaptchaAutoSolver)

> 基于浏览器端极速 OCR 引擎的全自动网页图形验证码识别与填充工具。0延迟、0干预、100%保护隐私，无需任何外部服务，无缝为你省下每一次敲击键盘的时间。

## ✨ 核心特性

- **🤖 全自动无感识别**：智能扫描网页中的验证码图片与输入框，自动提取、识别并瞬间填入。
- **⚡️ 极速纯前端引擎**：基于 **ONNX Runtime Web (WASM + SIMD)** 深度优化，识别速度达毫秒级，告别任何网络延迟。
- **🔒 100% 本地运行与隐私保护**：模型和推理引擎完全内置于浏览器离屏文档 (Offscreen Document) 中。**绝不发起任何外部网络请求**，彻底杜绝隐私数据外泄风险。
- **🪶 极致内存调度**：独创“按需唤醒”机制。在没有验证码的网页上占用 **0% CPU**；识别完成后闲置 3 分钟自动销毁推理引擎，**彻底释放后台内存**。
- **🧩 强兼容性**：底层使用 `HTMLInputElement.prototype.value` 原生劫持，并深度适配了基于 DOM 重绘或属性变动的单页应用（SPA，如 React / Vue / ElementUI）。

## 📦 项目结构 (纯浏览器扩展)

- **`manifest.json`**: 遵循 Chrome Manifest V3 标准，严格遵循最小权限原则（无指纹暴露风险）。
- **`content.js`**: 核心前端逻辑。负责 DOM 的智能扫描与变动监听、验证码图片的 Base64 提取，以及填入时的瞬态发光交互。
- **`background.js`**: Service Worker 调度中枢。负责按需创建 Offscreen 文档以及闲置超时（3分钟）后的内存回收。
- **`offscreen/`**: 内置的独立推理环境。加载 WASM 引擎并在后台默默执行 OCR 解码工作。
- **`models/`**: 经过 INT8 高度动态量化压缩的 ONNX 模型 (`common_q8.onnx`) 及对应的字符集，将几十MB的模型压缩至最适合扩展分发的体积。

## 🚀 快速开始

本项目已经彻底摆脱了传统的外部 Python 服务依赖，实现了开箱即用。

### 1. 安装 Chrome 扩展
1. 打开 Chrome/Edge 浏览器，进入扩展管理页面 `chrome://extensions/`
2. 开启右上角的 **“开发者模式”**
3. 点击 **“加载已解压的扩展程序”**，选择本项目文件夹即可。

### 2. 测试运行
1. 安装完成后，随意访问带有传统图形验证码的网页（例如各类系统登录页）。
2. 在页面加载完毕，或者**当你点击聚焦验证码输入框的瞬间**，扩展会自动截取图片并在后台高速解码。
3. 识别成功后会自动填入输入框，同时伴有轻微的优雅光晕提示你“搞定了”。
