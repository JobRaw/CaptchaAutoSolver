# 验证码自动识别助手 (CaptchaAutoSolver)

> 基于本地极速 OCR 引擎的全自动网页图形验证码识别与填充工具。0延迟、0干预、100%保护隐私，无缝为你省下每一次敲击键盘的时间。

## ✨ 核心特性

- **🤖 全自动识别**：智能扫描网页中的验证码图片与输入框，自动提取、识别并瞬间填入。
- **⚡️ 极速无感体验**：识别成功瞬间触发**动感双色瞬态光晕**（图片扫描红光 + 输入框填入绿光），1.5秒后自动淡出，**绝不留存任何刺眼线条**，保持页面纯净观感。
- **🔒 100% 本地运行**：采用轻量级 Python `ddddocr` 本地服务，无需联网，无 API 调用费用，彻底保障隐私数据安全。
- **🪶 极致轻量**：前端插件经过深度瘦身与代码重构，体积仅数十 KB，毫无运行负担。
- **🧩 强兼容性**：底层使用 `HTMLInputElement.prototype.value` 原生劫持，完美兼容 React / Vue 等现代前端框架。

## 📦 项目结构

- **前端插件 (Chrome Extension)**:
  - `manifest.json`: 遵循 Manifest V3 标准。
  - `content.js`: 核心逻辑，负责 DOM 扫描、截图提取、状态劫持与炫酷的瞬态光晕动画。
  - `test_demo.html`: 本地测试与调试专属 Demo 页。
- **后端服务 (Local OCR Server)**:
  - `ocr_server.py`: 基于 `ddddocr` 搭建的轻量级本地 Python API 服务 (运行于 `http://127.0.0.1:19999`)。

## 🚀 快速开始

### 1. 启动本地 OCR 服务
确保已安装 Python，并安装依赖：
```bash
pip install ddddocr flask flask-cors
```
运行服务：
```bash
python3 ocr_server.py
```
*(服务将静默运行在后台，内存占用极小)*

### 2. 安装 Chrome 扩展
1. 打开 Chrome 浏览器，进入 `chrome://extensions/`
2. 开启右上角的 **“开发者模式”**
3. 点击 **“加载已解压的扩展程序”**，选择本项目文件夹即可。

### 3. 测试运行
双击打开项目中的 `test_demo.html` 页面，验证码会在加载完毕的瞬间被自动识别并填入，同时你将看到优雅的瞬态光晕动画！
