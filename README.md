## ✨ 核心特性

- **🤖 全自动无感识别与操作**：智能扫描网页中的复杂验证码组件，极速定位目标元素。自动计算正确答案并模拟最逼真的人类拖拽交互。
- **🌀 工业级极坐标二维旋转配准**：应对变态级旋转验证码，采用自适应带宽的 **极坐标带状二维 ZNCC (Polar Band 2D ZNCC)** 模板匹配，无视内外图片比例错乱、重度噪点与抠图畸变，实现像素级精准旋转还原。
- **🧩 ZNCC 滑动缺口定位算法**：针对高光边缘、半透明拼图及深邃阴影，采用 **ZNCC（零均值归一化交叉相关）** + 两阶段领域精细提纯，免疫色彩与亮度干扰。
- **⚡️ 极速纯前端引擎**：基于 **ONNX Runtime Web (WASM + SIMD)** 深度优化文本 OCR 推理，结合纯 JavaScript 离屏 Canvas 高速图像特征匹配，识别速度达毫秒级。
- **🔒 100% 本地运行与隐私保护**：所有模型、视觉算法和推理引擎完全内置于浏览器离屏文档 (Offscreen Document) 中。**绝不发起任何外部网络请求**，彻底杜绝隐私数据外泄风险。
- **🪶 极致内存调度**：独创“按需唤醒”机制。在没有验证码的网页上占用 **0% CPU**；识别完成后闲置 3 分钟自动销毁推理引擎，**彻底释放后台内存**。
- **🎭 拟人化轨迹与强框架兼容**：拖拽模拟采用三段式贝塞尔缓动、随机 Y 轴抖动及 2~3px 微幅过冲回弹机制，完美绕过前端防风控拦截；底层深度适配 Vue / React / Element-UI 等单页应用。

## 📦 项目结构 (纯浏览器扩展)

- **`manifest.json`**: 遵循 Chrome Manifest V3 标准，严格遵循最小权限原则（无指纹暴露风险）。
- **`content.js`**: 核心前端逻辑。负责 DOM 的智能扫描与变动监听、验证码图片的 Base64 提取、坐标换算、拟人拖拽模拟及可视化调试参考线。
- **`background.js`**: Service Worker 调度中枢。负责按需创建 Offscreen 文档以及闲置超时（3分钟）后的内存回收与消息路由。
- **`offscreen/`**: 内置的独立推理与视觉匹配环境。加载 WASM 引擎执行 OCR 解码，并执行纯图像 ZNCC 边缘匹配算法。
- **`models/`**: 经过 INT8 高度动态量化压缩的 ONNX 模型 (`common_q8.onnx`) 及对应的字符集。

## 🚀 快速开始

本项目已经彻底摆脱了传统的外部 Python 服务依赖，实现了开箱即用。

### 1. 安装 Chrome 扩展
1. 打开 Chrome/Edge 浏览器，进入扩展管理页面 `chrome://extensions/`
2. 开启右上角的 **“开发者模式”**
3. 点击 **“加载已解压的扩展程序”**，选择本项目文件夹即可。

### 2. 测试运行
1. **旋转验证码**：当弹窗显示旋转验证码（如移动端框架）时，插件将自动进行特征边缘 2D ZNCC 分析，并精准反向旋转对齐。
2. **滑动拼图验证码**：自动感知滑块与背景图、在后台极速计算缺口坐标，并模拟人类轨迹完成拖拽滑动校验。
3. **文本验证码**：访问带文本验证码的页面，扩展会自动截取图片并离线高度解码填入。
